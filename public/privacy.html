Privacy

KIM3310 Systems Gallery is a public portfolio and commercial routing page. Do not submit secrets, private datasets, credentials, or sensitive personal data through public GitHub issues.

Analytics

Google Analytics starts with Consent Mode denied. The footer consent control can enable aggregate analytics. Commerce CTA events, when enabled, use lane-level metadata only.

Checkout and Inquiries

Hosted checkout links may point to a provider such as Lemon Squeezy or Polar when configured. If no checkout URL is configured, the site falls back to a GitHub issue inquiry.

Data Requests

Use the public inquiry route only to request a private contact path. Identity, deletion, export, billing, and support requests require an approved private channel before personal data is collected.
